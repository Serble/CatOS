; CatOS console font: 129 glyphs, 8x16 pixels each.
;
; Each glyph is a `glyph <code>` line followed by 16 rows of 8 pixels, '#' set
; and '.' clear. Glyphs must appear in order starting from 0, since the code
; is the glyph's index in the packed blob (and its tile number in the PPU).
; Lines starting with ';' and blank lines are ignored; anything after the code
; on a glyph line is a label for humans.
;
; tools/mkfont.py packs this into build/font.bin (1bpp, one byte per row, MSB
; = leftmost pixel), which raylibppu.cat embeds. Originally derived from the
; x86 testos 8x16 console font.
